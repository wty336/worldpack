## 4. F5：Web 前端

- `game_agent/web.py`：FastAPI 会话 API（new / turn / status / actions / save / load）+
  **POST-SSE 流式回合**（`delta` 事件 = 叙事增量、`done` = 完整视图 JSON、`error` = 结构化
  错误），复用引擎 `on_text` 回调——与 CLI 同一条流式管线；
- 内嵌极简聊天页（原版 JS，无构建）：剧情区 + 关键抉择渲染 + 选项/发言 + 日程行动按钮 +
  存档读档 + 状态栏；
- `python -m game_agent web [--port]` 启动；usage 记账接入（saves/usage-web.jsonl）。

### 验收证据

- 离线 TestClient（4 项）：页面/开局→抉择（SSE delta 逐段到达）→发言→存读档/状态/行动
  （P2 requires 门槛在 Web 端同样生效——未结识时备礼探访不可用）；
- 真机 uvicorn（`scripts/web_smoke.py`）：开局 → 关键抉择 → 发言 → 行动列表 → 存读档，
  全流程在浏览器协议层跑通。
- **⚠️ 表述修正（审查修复 B-1/M3）**：P3 验收时的「617 个流式增量」只证明了**最终字节序列**，
  **未证明时序流式**——当时同步生成器先跑完 LLM 调用才 drain 队列，客户端在生成期间收不到
  任何字节。批次 B（B-1）已重写为工作线程 + 队列的真流式：离线时序测试断言「首个 delta
  到达时 LLM 仍在生成」；真机实测**首个增量 5.9s / 总时长 15.4s**（边生成边到达）。
