## 2. 为什么第 5 件（事实图 Judge）在训练暂停期价值反转

训练计划里 judge 的最大实测缺口是 **confab「缺席证据」漏 70%**（14B 拦 27.5~32% vs flash 82~90%），
原路线用 LoRA 蒸馏补这个缺口。**事实图 Judge 用代码治同一缺口**：关键事实入图 →
判官出候选矛盾 → 代码对照图验证"材料里有没有这条事实"（查无此事实 = confab）。
训练暂停期间，这是**不训练而补 judge 缺口**的正路，且沿用同一把语料尺子验收。

## 3. 执行记录 · 第 1 件：query_world 只读查询工具 ✅（2026-09-24）

### 3.1 设计

- **工具契约**（`llm.py` `build_tools`）：`query_world(query)` 唯一必填参数；
- **引擎纪律**（`context.py` `ENGINE_RULES` 第 8 条）：查到的才写、查不到的不得编造；
  查询结果只作叙事依据，不得原样复述给玩家；
- **处理器**（`game.py` `_query_world`）：只读组装——
  地点/时间/行动点 → 在场 → 属性/好感 → 主线目标 → 相关关键事实/NPC 记忆/lore
  （复用 `rank_facts` / `select_lore`，与状态栏注入同口径）→ 可选行动；
- **两条硬边界**：
  1. **只读**：处理器零写入（守卫测试用 `state.copy()` 前后对拍钉住）；
  2. **不泄 flags**：剧情旗标是引擎内部真值，查询结果不含任何 flag 键名/原值
     （状态栏本来也不带 flags，同口径）。

### 3.2 为什么零耦合

- 只改 turn 侧（工具 schema + ENGINE_RULES 静态前缀）；judge/compress/extract/reflect/dedup
  各有独立 system prompt，**不受影响**；
- turn 侧没有冻结基线（冒烟是端到端通过/失败，不是数字基线）→ 无重测成本；
- 训练数据（turn 属于 Phase 2，本就未采）零过期。

### 3.3 守卫

`tests/test_query_world.py` **10 条**（内容 7 + 协议 3）；
`tests/test_llm.py` 工具数断言 3 → 4 + query_world schema 检查。
全量回归：**590 → 600 passed**。

### 3.4 待观察

- 真机玩一轮观察 query_world 的调用频率与结果质量（模型是否会滥用/不用查询）；
- 若查询结果过长为上下文负担，收紧 k/pinned（当前 5/3、2）或加字符上限。

### 3.5 执行记录 · 第 2 件：关键节点内轮自校正（Reflexion）✅（2026-09-24）

**设计**（`game.py` `_critique_and_regenerate` + `_generate_turn` 重构）：

- **触发**：`critique_on_critical=True`（cli/web 已接）且当前节点带 `critical_choices`；
- **判定**：复用 JudgeSystem（同一把被 E1 语料门禁背书的尺子，不加新提示词面）——
  `False + 有判词` → 附结构化反馈重生成一次（**至多 2 稿**）；`通过`/`未知` → 不重生成；
- **剥稿**：重生成后从历史中剥掉第一稿与反馈（防"两个版本都当真"污染后续上下文；
  第一稿的工具效果已落 stat_log 真值，不丢）；实现 = 以反馈消息为标记切出第二稿；
- **流式纪律**：关键节点生成期**不流式**（坏稿不能让玩家先看到），验收后整稿回放一次
  （CLI 的 last_streamed 去重逻辑天然兼容）；
- **不熔断**：第二稿仍判劣也接受——自校正是质量优化层，不是硬门禁；
- **turn_count 口径**：每玩家可见回合 +1，重生成不另计（记忆来源追踪不受影响）。

**守卫**：`tests/test_critique.py` **9 条**（触发条件 3 / 判定三态 2 / 剥稿 2 / 流式缓冲 2）。
全量回归：**600 → 609 passed**（待最终回填）。

**待观察**：

- 真机关键节点实测：judge 判劣率与重生成后的改善幅度（建议打开 `GAME_AGENT_TRACE`
  看 turn_begin/turn_end 成对出现 = 发生了重生成）；
- 成本：关键节点回合会多 1~2 次 judge 调用，长局成本曲线需观察（usage 账本自动记账）。

### 3.6 执行记录 · 第 3 件：BM25 词面检索 ✅（2026-09-24）

**选型**（用户确认）：本地无依赖 BM25 式升级，不接 embedding——数据量小（≤24 事实/≤20 记忆）、
每轮调用、零成本零依赖；embedding 留作可插拔接缝。

**设计**（`game_agent/memory.py` A1 v2）：

- 词项 = **单字 + 二元组**：单字扛召回（v1 纯二元组口径「我的剑叫什么」vs「剑名是听雨」
  零重叠，v2 共享单字「剑」命中）、二元组扛区分；
- **桶内局部 IDF**：稀有词（听雨/桂花糕）权重高，常用词（玩家/的/了）被压制；
- **长度归一化** + **分数桶内归一化**（relevance 仍落在 0~1，α/β/γ 三因子语义不变）；
- **可插拔接缝**：`rank_facts(..., relevance_fn=bm25_scores)`——embedding ranker
  同签名 `(query, docs) -> scores` 接入即换，不动调用方；
- **不动**：去重预筛的 `_bigrams`（另一机制）、`select_lore`（keyed 检索，语义不同）；
- 选择语义不变：常驻区（top importance）+ 检索区 top-K，**无分数阈值过滤**——
  工厂材料装配的"in_material anchors 必在位"校验不受影响（小桶全注入）。

**守卫**：`tests/test_bm25.py` **8 条**（词项/IDF/改写召回/零命中/归一化/接缝/常驻区不变）。
全量回归：**609 → 617 passed**。

**耦合面重测**（§3.6.3）：

- 离线：场景卡工厂、A1/A4、context/query_world/lorebook 相关测试全部重跑通过；
- 真机：E1 Judge 门禁重测（材料排序变化 → 按"换尺子不换两侧 = 假对比"纪律补跑）——
  `reports/judge_sensitivity_20260924-150148.json`（ancient_jianghu，flash，¥0.214）：
  **ooc 20/20 · setting 22/22 · confab 20/20 = 100% · normal 误报 3/48 = 6% ✓ 门禁通过**，
  与改动前同口径无退化（其余两包待后续真机批次一并补跑）。

### 3.8 执行记录 · 第 5 件：事实图 Judge（confab 缺席证据代码化）🔄（2026-09-24）

**设计**：`docs/design-factgraph.md`。实现要点：

- `game_agent/factgraph.py`：图从**材料同源真值**构建（pack+state：玩家事实/NPC 记忆/
  lore/NPC 卡/场景/数值），不含 flags；两级判定 = factcheck 侧信道（purpose="factcheck"，
  temp=0，预算 500，要点式输出）抽"新确立的承诺/债务/事实" → 代码查缺席；
- `JudgeSystem.check(narration, materials, state=None, pack=None)`：图违规 → **确定性
  False**（LLM 未知时也照常工作）；state/pack 缺省 = 图检查关闭（旧调用方零改动）；
- `judge_corpus.build_state`（`build_materials` 复用）→ E1 语料与真实局同一建图路径；
- game 两处调用点（judge_every 与关键节点自校正）已接 state/pack。

**口径收敛（E1 实测驱动，三次迭代）**：

1. 初版"2~4 字锚点、任一缺席即违规"→ 2 字伪锚点满屏误报；
2. 改为"3~4 字强锚点全缺席才违规"→ confab 20/20 ✓ 但 normal 误报 12%（6 条）：
   2 字专名（听雨/东市/银两）无法接地、中文数字不匹配（五十两 vs 50）、
   抽取器把"师父剑谱"类背景铺垫当断言；
3. 收敛：**接地窗口放开到 2~4 字**（2 字只帮接地不触发违规）+ **抽取器排除背景铺垫
   与玩家状态描述**（状态由引擎维护，不可能"新确立"）→ 图层误报清零。

**E1（ancient_jianghu，flash）**：confab **20/20 = 100%**（此前 14B 零样本仅拦 ~32%，
flash 82~90%——缺席证据路线被代码机械补齐）；normal 误报率回归基线噪声水平
（基线 3/48 为 LLM judge 既有噪声，图层 0 新增——数字以最终报告为准）。
**成本**：每次 judge 检查多一次 factcheck 调用，E1 单包约 +¥0.1。

**守卫**：`tests/test_factgraph.py` **13 条**（建图/解析/缺席/接地/2 字专名/部分接地/
静默/合并语义/向后兼容/语料同源）。全量回归：**633 → 646 passed**。

**待办**：xianxia_wendao / urban_neon 两包 E1 补跑（约 ¥0.6）；T1/T2 切片报数验证
