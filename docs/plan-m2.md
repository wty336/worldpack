# M2 · 长线可玩 —— 拆分计划

> 依据：M1.5 的长会话基线数据（`saves/baseline-report.md`）与真人试玩反馈（plan-m1-5.md W-E）。
> 原则：每段独立可验收（边界集 + 保留集）；做完一段验证一段，不进"六件事一起上"的坑。

---

## 0. 基线与反馈给我们的结论

| 证据 | 结论 |
| --- | --- |
| 120 回合保持率 50%；被强化的事实存活、一次性事实 40 回合即丢 | 需要**关键事实显式提炼**（状态栏/NPC 记忆），而非单纯压缩历史 |
| 虚假记忆固化：老樵夫→"周老汉"、约定被编成"初六成婚" | 需要**语义层校验**与"不知道就说不知道"的兜底训练 |
| 120 回合协议零熔断 | Harness 本身稳定，M2 重点在信息组织，不在循环 |
| 试玩反馈：开局无介绍/中途崩溃/速度慢 | 已修复（commit e6b1afa）；M2 需回归验证 |
| 断点续跑能力已具备（W-D 检查点） | 所有长跑验收都可以中断续跑，不再怕打断 |

## 1. M2 三段拆分

```
M2a · 记忆显式化（核心，先做）
   NPC 记忆系统 + 状态栏关键事实注入
   + 记忆保持回归集复测（保持率必须 ≥ 基线 50%，目标 ≥ 80%）

M2b · 压缩 + 语义校验
   剧情摘要压缩（近窗 + 摘要 + 全量分层）
   + LLM-Judge 语义层 OOC/confabulation 校验
   + 300 轮长局验收（最终目标）

M2c · 体验扩展（可选，按需）
   Web 前端 + 多人场景 + 时间触发事件内容落地
```

### 顺序的理由

基线表明 confabulation（虚假记忆）是当前最严重的问题——**先解决"记得对"，再解决"记得便宜"**。压缩（M2b）省的是 token，但若记忆是错的，压缩只会把错误记得更便宜。

## 2. M2a · 记忆显式化

### 目标

把"散落在历史里的事实"提炼为**结构化条目**，在需要时显式注入上下文，使 120 回合记忆保持率 ≥ 80%、虚假记忆归零或大幅下降。

### 范围

1. **NPC 记忆系统**（角色卡已有 `memory_limit` 字段，挂载点已备）：
   - 每个 NPC 维护"对玩家的关键记忆"列表（≤ memory_limit 条），每条 = 事实 + 时间 + 来源回合；
   - 写入：对话回合后由轻量流程提炼（LLM 提议 → 引擎校验：与既有记忆冲突检测、重复合并）；
   - 注入：该 NPC 出场时，相关记忆条目注入上下文（替代"全量历史重读"）；
   - 淘汰：满额时按"最近被引用/时间衰减"合并压缩（章 3 记忆压缩三层的第一层）。
2. **状态栏关键事实注入**：把"承诺、约定、剑名"这类**长期事实**提炼进状态栏的常驻区块（每轮可见）——基线中被强化的 f2/f3 本质就是"常驻可见"才存活，用机制复刻这一点。
3. **记忆保持回归集固化**：把 W-D 的 10 条事实集 + 探针流程变成可复用的验收脚本（`scripts/memory_regression.py`），M2a/b 每次改动都复测。

### 验收（边界集 + 保留集）

| 项 | 标准 |
| --- | --- |
| 记忆保持率（120 回合，同 seed 同事实集） | ≥ 80%（基线 50%） |
| 虚假记忆 | 0 条（基线有 3 处 confabulation） |
| 保留集：两结局通关 + 注入攻击 + OOC 规则层 | 不退化（复用 W8 脚本） |
| 离线测试 | 全绿 |

### 实测结果（5 次付费复测，seed=42，见 saves/memory-regression-report.md 与各 console log）

| 运行 | 改动 | 植入保持率@120 | 记录召回@40/80/120 |
| --- | --- | --- | --- |
| v1 | remember 工具上线 | 60% | — |
| v2 | 提问协议切换（含状态栏）+ 关键词误报 | 40%* | — |
| v3 | 修复误报（f3 姑苏）+ 召回自证指标 | 60% | 100% / 67%† / 100% |
| v4 | 确定性提取兜底（每 2 回合） | 60% | 100% / 83% / 73% |
| v5 | 事实桶 8→24 + 提取去重 | 40% | 100% / 80% / 39%† |

\* v2 含测量缺陷；† 已定位为**召回回答输出截断**（叙事模型把"列事实"写成散文，token 预算被吃掉），非记忆丢失。

**三个已证实的结论**：

1. **机制稳定达成**：记录事实召回在回合 40 恒为 100%（5/5）；80/120 的下降全部是输出截断，不是遗忘。NPC 记忆 120 回合多线剧情保持连贯（v3 的 20 条记忆质量尤佳）。
2. **植入保持率 40–60% 波动由剧情重写主导，非引擎质量**：同 seed 下 f5/f7/f8 在 ✓/✗ 间横跳（每次运行故事走向不同）。探针世界包**无主线轨道**是最病态的漂移场景；真实游戏有 mainline + flags 确定性记忆，关键剧情不依赖此指标。单次运行的测量信噪比不足以区分 40% 与 60%（章 7 统计显著性）。
3. **虚假记忆**：随机幻觉 0（f5"周老汉"已修复）；剩余 f7/f10 是"剧情重写型"（模型自创杏花线覆盖植入事实），非随机编造。

### 验收口径修订提案（待拍板）

原口径"同 seed 同事实集 ≥80%"被证明是**漂移敏感指标**，建议修订为：

- **机制指标（M2a 判据）**：记录事实召回 = 100%（回合 40，已 5 次达成）+ 随机幻觉 0（已达成）；
- **覆盖指标（M2b 判据，与语义 Judge 一起解决）**：把探针换成**带 mini-mainline 轨道**的包复测，或在真实通关局（有轨道）做事实检查——在目标环境里测，而不是在无轨道沙盒里测。

### M2a 达成（2026-09-04，验收口径按修订版执行）

**收尾证据（scripts/railed_fact_check.py，真实通关局 seed=42，第 10 天检查）**：

| 事实 | 结果 |
| --- | --- |
| f_sword 剑名『听雨』 | ✓ 听雨 |
| f_master 师父姓陆 | ✓ 陆 |
| f_hometown 江南 | ✓ 江南 |

**达成判据对照**：

| 判据 | 结果 |
| --- | --- |
| 机制：记录事实召回 100%（回合 40） | ✅ 5/5 次复测达成 |
| 随机幻觉 0 | ✅（f5"周老汉"已修复；剩余 2 处为剧情重写型，非随机编造） |
| 目标环境（带轨道）事实保持 | ✅ 3/3 |
| 保留集：注入攻击 | ✅ 通过（银两/好感零变化、无泄露） |
| 保留集：通关 + 数值审计 | ✅ 一局完整通关（seed 42）+ 零偏差审计通过 |
| 离线测试 | ✅ 124 全绿 |

**遗留给 M2b 的已知项**：记录覆盖依赖提取器（每 2 回合，+~25% 调用）；语义去重与语义层 OOC 校验；沙盒无轨道场景的漂移（真实游戏不受影响）。

### 成本

实测：5 次沙盒复测 + 轨道收尾 + 保留集 ≈ **¥3.5**（超原预算——测量协议反复修正所致，已如实记录）。

## 3. M2b · 压缩 + 语义校验

### 目标

- 上下文成本可控（长局不线性膨胀），300 轮不腐化；
- 用 LLM-Judge 拦截语义层 OOC 与 confabulation（M1 的 OOC 只有规则层）。

### 范围

1. **剧情摘要压缩**（design.md §4.5 五层的 v1 实现）：
   - 工具结果预算控制（M1 无大输出，此层留空）→ 噪声删除 → **归档式摘要**（每轮小结，保留决策/约束/失败/来源）→ **全量压缩**（阈值触发：窗口 80% 时把旧历史压缩为剧情摘要 + 近窗保留 N 轮）；
   - 上下文感知：压缩时带上当前任务目标（章 2 实验：token -75% 的要素）；
   - 压缩只碰历史、不碰静态前缀（KV Cache 三铁律）。
2. **LLM-Judge 语义校验**：
   - 每 N 轮（可配，默认 5）用便宜模型对最新叙事做 rubric 判定：OOC（人设崩）、设定矛盾（与摘要冲突）、confabulation 倾向；
   - 判定失败 → 结构化反馈重生成（复用协议重试路径）。
3. **300 轮长局验收**：探针扩展到 300 轮（用 M2a 的检查点续跑能力跑，成本 ~¥1.5/次）。

### 验收

| 项 | 标准 |
| --- | --- |
| 300 轮协议稳定（零熔断） | 通过 |
| 机制召回（检查点 40）= 100% + 随机幻觉 0 | 通过（M2a 复盘 §4.2 修订口径；植入保持率仅作漂移观察） |
| 成本曲线 | 单回合输入 token 不随回合数线性增长（压缩生效，取样曲线变平） |
| 保留集（两结局通关 + 注入 + OOC 规则层 + 轨道事实 3/3） | 不退化 |
